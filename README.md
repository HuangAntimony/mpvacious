# mpvacious 双语字幕过滤版（Fork）

本仓库是 [Ajatt-Tools/mpvacious](https://github.com/Ajatt-Tools/mpvacious) 的 Fork 版本，专门针对**日语学习者观看双语字幕**的场景进行了优化。

## 新增功能

### 🎯 双语字幕自动过滤

在观看带有中日双语字幕的视频时，自动识别并提取日语行，过滤掉翻译文字，让你专注于日语原文。

#### 核心特性

| 功能 | 说明 |
|------|------|
| **自动检测字幕类型** | 自动判断当前字幕是「纯日语」还是「双语」 |
| **智能位置识别** | 自动判断日语行在上方还是下方 |
| **假名检测** | 通过检测平假名/片假名来识别日语内容 |
| **锁定机制** | 连续5次检测一致后锁定判定结果，避免误判 |
| **标注行过滤** | 自动忽略 `(男)`、`[音楽]`、`（効果音）` 等标注行 |

#### 工作原理

1. **检测阶段**：脚本会观察字幕的行数和内容
  - 单行有假名 → 计入纯日语证据
  - 两行中只有一行有假名 → 计入双语证据，并记录日语位置
  - 两行都有假名 → 计入纯日语证据

2. **锁定阶段**：当某类证据累计达到5次时
  - 锁定为「纯日语」模式：不做任何过滤
  - 锁定为「双语」模式：自动过滤非日语行

3. **过滤逻辑**（双语模式已锁定）：
  - 单行：有假名保留，无假名过滤为空（视为纯翻译行）
  - 双行：优先按假名检测，都没假名时按已知位置返回一行
  - 3行：提取含假名的行，都没假名时返回原文
  - 4行：分两组处理，每组按假名/位置返回一行
  - 5行+：提取含假名的行，都没假名时返回原文

### ⌨️ 新增快捷键

| 快捷键 | 功能 |
|--------|------|
| `Alt+m` | 切换双语过滤（开启/关闭/重置检测） |
| `Alt+d` | 调试面板：实时显示字幕过滤状态（再按关闭） |

### 📊 菜单状态显示

在 mpvacious 菜单（按 `a` 打开）中新增了双语过滤状态行：

```
Bilingual filter: 检测中 (单语:3/双语:0)
Bilingual filter: 双语 (日语在上)
Bilingual filter: 纯日语
Bilingual filter: 关闭
```

### 🔧 其他改进

1. **括号内容处理优化**
  - 原行为：删除所有括号及其内容
  - 新行为：如果整个字符串被括号包裹，则保留不变
  - 示例：`（効果音）` 作为独立行时会被保留

2. **换行符处理优化**
  - 原行为：将换行符替换为空格
  - 新行为：直接删除换行符
  - 这对日语文本更合理，因为日语不使用空格分词

## 使用场景

本 Fork 特别适合以下场景：

- ✅ 观看带有「日语原文 + 中文翻译」双语字幕的动画/日剧
- ✅ 使用 mpvacious 制作 Anki 卡片时，只想导出日语原文
- ✅ 复制字幕到剪贴板时，只想复制日语部分

## 安装

与原版 mpvacious 相同，将本仓库克隆到 mpv 的 scripts 目录：

```bash
# Windows (portable_config)
git clone https://github.com/YOUR_USERNAME/mpvacious.git "mpv目录/portable_config/scripts/subs2srs"

# Linux
git clone https://github.com/YOUR_USERNAME/mpvacious.git ~/.config/mpv/scripts/subs2srs
```

## 配置

所有原版配置选项仍然有效。双语过滤功能默认开启，可通过 `Alt+m` 快捷键切换。

## 注意事项

1. **副字幕不受影响**：双语过滤只应用于主字幕，副字幕（secondary subtitle）保持原样
2. **检测需要时间**：需要观看几条字幕后才能完成类型判定
3. **手动重置**：如果字幕类型判定错误，按 `Alt+m` 可以重置检测
4. **Anki-Connect**：观看时需打开Anki以保证Anki-Connect处于活跃状态，否则输出字幕到剪切板时可能出现严重卡顿

## 快速参考

```
Alt+m  → 第一次按：重置检测（如已锁定）或关闭过滤
         第二次按：开启过滤并重新检测
         
Alt+d  → 开启/关闭实时调试面板：
         ═══ 双语过滤调试面板 ═══
         【原始】日本語テキスト ⏎ 中文翻译
         【过滤】日本語テキスト
         【状态】双语 (日语在上)
         (Alt+d 关闭)
```
